# Provider brand assets

These SVGs are bundled locally so the dashboard never makes runtime logo requests.

- `openai.svg`: `OpenAI-black-monoblossom.svg` from OpenAI's official 2025 logo pack.
- `claude.svg`: `ClaudeIcon-Square.svg` from Anthropic's official press kit.
- `opencode.svg`: `opencode-logo-dark.svg` from OpenCode's official brand asset pack.

Retrieved from the providers' official sites on 2026-08-28. The official xAI/Grok asset package returned HTTP 403 during the audited retrieval, so Grok intentionally uses a text-only product-name fallback instead of a traced or third-party logo.
