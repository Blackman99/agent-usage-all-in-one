# Provider brand assets

These SVGs are bundled locally so the dashboard never makes runtime logo requests.

- `openai.svg`: `OpenAI-black-monoblossom.svg` from OpenAI's official 2025 logo pack.
- `xai-light.svg` and `xai-dark.svg`: unmodified inline xAI logo variants served by
  the official [SpaceXAI Brand Guidelines](https://x.ai/legal/brand-guidelines)
  page on 2026-08-28. The guidelines require exact use without alteration and
  may revoke permission; review them before release.
- `claude.svg`: `ClaudeIcon-Square.svg` from Anthropic's official press kit.
- `opencode.svg`: `opencode-logo-dark.svg` from OpenCode's official brand asset pack.

Retrieved from the providers' official sites on 2026-08-28. The downloadable
xAI/Grok asset package returned HTTP 403 during the audited retrieval; the
official page-hosted SVG variants above were therefore used without alteration.
